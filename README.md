# My Policies

A React app that displays a user's insurance policies with pagination.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS

## Features

- Lists active insurance policies sorted by start date
- Shows 3 policies per page with pagination
- Responsive design — mobile-first layout
- Loader while data loads

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
